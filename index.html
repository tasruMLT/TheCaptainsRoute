Harbour Run

Cruise ship is blue. Pirate ship is yellow. Screen is locked for focus play.

Player 1

Default Move: W A S D

Default Attack: Space

Player 2 (Local Mode)

Default Move: Arrow Keys

Default Attack: Right Shift

Menu

1 = Single Player vs Computer

2 = Local 2 Player

K = Settings (custom gameplay + key bindings)

Shop: Enter to buy, Backspace to sell, Tab to switch player
